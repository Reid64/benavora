# Final Chain-It Implementation Directive

This specification package is dependency-complete for the 44-agent PIL fleet. Implementation must proceed in the target repository without claiming unexecuted tests.

1. Inspect repository, governing instructions, current changes, architecture, provider contracts, and deployment topology.
2. Validate/migrate all shared contracts and canonical registries.
3. Implement/verify deterministic control-plane and intelligence services before dependent agent runtimes.
4. Implement agents in dependency order: Knowledge Integrity foundations → Intelligence → Relationship → Qualification → Strategy → Fleet Learning, while preserving existing Supervisory/Discovery contracts.
5. For every agent, produce durable goal/run/plan state, typed capabilities/delegation, evidence integration, policy/budget middleware, events, APIs, observability, tests, ADRs, and runbooks.
6. Execute G0–G5. Never convert a missing test into a passing test.
7. Produce an evidence bundle: revision, traceability, schema results, unit/integration/E2E, replan traces, tenant/security tests, recovery, critic independence, budget enforcement, load/soak/chaos/DR, residual risks.
8. Score only inspected implementation. Production-ready requires ≥95/100 and all blocking gates.
9. Preserve the 44-agent count unless a formal architecture-change proposal proves a new independently bounded goal-owning reasoning domain.
10. Treat Corporate Application Automation as downstream and version its new agents/services separately after overlap analysis.
